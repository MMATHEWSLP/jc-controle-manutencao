# Planilha do histórico de abastecimento

Coloque aqui o arquivo `Historico_de_Abastecimento_LIMPO_2026-09-29.xlsx`, com esse nome exato. É o caminho
padrão lido por `importar-abastecimento.mjs` e pelo workflow "Importar histórico de abastecimento
(Arapiuns)".

Só a aba **Dados_Limpos** é importada. As abas de auditoria (Revisar_Combustivel_Ausente,
ARLA_Teste_Removido, Duplicatas_Removidas, Responsavel_Invalido e Rodape_Removido) são ignoradas.
